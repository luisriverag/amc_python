Opis ".amc" - formatu własnego katalogu

Dane ogólne

Wszystkie zmienne są zmiennymi Pascala, jako że program powstał w Delphi.

Każde pole "tekstowe" jest poprzedzone zmienną integer (4 bajty, ze znakiem), która określa rozmiar wektora (wartość = 0 jeśli brak wektora np. pusty tekst). Zatem teksty w katalogu są zmiennymi string (znak = 1 bajt, bez znaku) bez znacznika końca.

"Boolean" = 1 bajt; 0 jest False, inne wartości True.

W przypadku pól filmu, data jest zapisywana TDateTime Borland: liczba dni od 30/12/1899.
Dla pól niestandardowych typu dane, data przechowywana jest w sformatowanym ciągu jako 'yyyy-mm-dd'
Dla pól niestandardowych typu rzeczywistego, data przechowywana jest wsformatowanym ciągu jako 'x.xxx'

Pole "Picture" jest tablicą bajtów, zawierającą plik obrazka w oryginalnym formacie (PNG/JPEG/GIF/BMP).
Format określony jest w polu "PictureName" poprzedzającym "Picture".
Jeśli rozmiar obrazka > 0, to PictureName zawiera oryginalne rozszerzenie pliku ('.png', '.jpg', '.gif' or '.bmp'). Jeśli rozmiar pliku = 0 to PictureName zawiera odnośnik do okładki (względny lub bezpośredni), lub nic gdy nie został przypisana do filmu żaden obrazek.

Plik zaczyna się 65-bajtową ustaloną długością tekstu (tzw. "strFileHeader42"), na początku i na końcu (pierwszy bajt pliku jest spacją).
Jeden blok z kilku ciągów znaków zawiera informacje o właścicielu katalogu, drugi o właściwościach pól niestandardowych (od AMC 4.0), a następny filmy i dodatki (od AMC 4.2).

Wersja 4.2

Nagłówek:

strFileHeader42 = ' AMC_4.2 Ant Movie Catalog 4.2.x   antp/soulsnake    www.antp.be ';

Informacje o właścicielu katalogu:

OwnerName:                string;
OwnerSite:                string;
OwnerMail:                string;
OwnerDescription:         string;

Właściwości pól niestandardowych:

ColumnSettings:           string;
GUIProperties:            string;
Length(CustomFieldsProp)  Integer;
CustomFieldsProp:         array of struct CustomFieldProp (zobacz poniżej)

Właściwości pól niestandardowych (CustomFieldProp):

FieldTag:                 string;
FieldName:                string;
FieldExt:                 string;
FieldType:                string;
DefaultValue:             string;
MediaInfo:                string;
MultiValues:              Boolean;
MultiValuesSep:           Char; // Przechowywane jako Integer
MultiValuesRmP:           Boolean;
MultiValuesPatch:         Boolean;
ExcludedInScripts:        Boolean;
GUIProperties:            string;
if FieldType = 'ftList' then
| Length(ListValues)      Integer
| ListValues:             array of string;
| ListAutoAdd:            Boolean;
| ListSort:               Boolean;
| ListAutoComplete:       Boolean;
| ListUseCatalogValues:   Boolean;
