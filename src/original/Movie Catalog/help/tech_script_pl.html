Tworzenie skryptów

Plik skryptów są zwykłymi plikami tekstowymi, więc możesz jest modyfikować w dowolnym edytorze. Ale używając wbudowanego w Ant Movie Catalog można łatwo ustalić nagłówek skryptu poprzez okno parametrów skryptu.

Język skryptu podobny jest do Pascala lub Delphi. Jeśli nigdy nie używałeś Pascala, ale znasz się nieco na programowaniu (C, C++, PHP, Java lub inny) powinieneś łatwo opanować zasady, studiując działanie istniejących skryptów.

Używany tu silnik skryptowy, to 2 wersja Carlo Kok's Innerfuse Pascal Script.

Wykorzystywana jest większość podstawowych funkcji. Dodano również kilka funkcji i stałych do wymiany danych z Ant Movie Catalog. Postaram się tutaj je przybliżyć.

Skrypt rozpoczyna się blokiem komentarza, który nie jest widoczny podczas edycji w edytorze Ant Movie Catalog. Blok ten zawiera parametry, które mogą być zmieniane przez okno parametrów skryptu.

Oczywiście zostaną znalezione i wyświetlone tylko te pliki skryptów, które znajdują się w folderze "Scripts". These must have a ".ifs" extensoin. The files with a ".pas" extension are meant to be included by scripts, to provide additional functions. For example, StringUtils1.pas contains a set of functions to help handling and parsing text strings.

To include one of these files un de ces fichiers, a reference to it has to be put after the "uses" keyword in the beginning of the code:

program NewScript;
uses
  file1, file2;

In this example, this will allow the script to call functions and variables contained in file1.pas and file2.pas.

function CheckVersion(Major, Minor, Revision: Integer): Boolean;
Zwraca True, jeśli aktualna wersja programu jest przynajmniej wersją określoną w parametrach.

function AcceptLicense(LicenseVersion: Integer): Boolean;
Wyświetla w oknie skryptu pole o treści "Licencja" określone w oknie właściwości przyciski typu "Zgadzam się" i "Anuluj". Gdy licencja została zaakceptowana, nie musisz akceptować jej ponownie, chyba że zmieniły się parametry numeru licencji. Pozwala to wyświetlić okno dla wszystkich użytkowników po zmianie licencji, ale nie drażnić ich przy każdym wykonaniu skryptu.

Functions to manage cookies

procedure AddCookie(cookie: string; hostOrUrl: string);
Adds a new cookie or change its value and its properties for specified host or url.
Examples:
- AddCookie('cok=1; path=/film', 'http://www.example.com'): Add cookie 'cok=1' for host 'www.example.com' with propertie 'path=/film' (this cookie will be only visible for url starting with 'http://www.example.com/film/').
- AddCookie('cok=1; path=/', 'http://www.example.com'): Add cookie 'cok=1' for host 'www.example.com' with propertie 'path=/' (this cookie will be visible for url starting with 'http://www.example.com/').
- AddCookie('cok=1', 'http://www.example.com'): Same as previous example, 'path=/' by default.
- AddCookie('cok=1; max-age=10', 'http://www.example.com'): Add cookie 'cok=1' for host 'www.example.com' with propertie 'max-age=10' to delete this cookie in 10 seconds.
- AddCookie('cok=1; expires=Sun, 07-Aug-2016 16:43:12 GMT', 'http://www.example.com'): Add cookie 'cok=1' for host 'www.example.com' with propertie 'expires=Sun, 07-Aug-2016 16:43:12 GMT' to delete this cookie after this date.
- AddCookie('cok=1; max-age=0', 'http://www.example.com'): Add cookie 'cok=1' for host 'www.example.com' with propertie 'max-age=0' to delete this cookie immedialy.
- AddCookie('cok=1; expires=Thu, 01-Jan-1970 00:00:01 GMT', 'http://www.example.com'): Add cookie 'cok=1' for host 'www.example.com' with propertie 'expires=Thu, 01-Jan-1970 00:00:01 GMT' to delete this cookie immedialy.
- AddCookie('cok=', 'http://www.example.com'): Add cookie 'cok=' for host 'www.example.com' to delete this cookie immedialy.

procedure SetCookies(cookies: string; hostOrUrl: string);
Adds new cookies or changes its values for specified host (e.g. nameCookie1=valueCookieC; nameCookie2=valueCookieD; nameCookie3=valueCookieE).
This function do not support add of properties for cookies (use AddCookie function for this). The 'path' used for cookies is '/'.

Funkcje do wyciągania informacji ze stron internetowych

function GetPage(address: string): string;
Pobiera stronę HTML (lub inny plik tekstowy) za pomocą metody GET i zwraca ją jako ciąg znaków.

function GetPage2(address: string; referer: string): string;
Taka sama funkcja jak GetPage, ale pozwala określić adres "referencyjny" (strony, która wywołała następną). The default value is an empty string.

function GetPage3(address: string; referer: string; cookies: string): string;
Taka sama funkcja jak GetPage2, ale pozwala określić pliki cookie jako ciąg znaków: np. "uid=120; pwd=FHNHESW".

function GetPage4(address: string; referer: string; cookies: string; content: string): string;
Same as GetPage3, but allows to specify the content-type as a string; by default for other versions the value is '*/*' for compatibility with old versions; you can pass '' for a more standard call.

function GetPage5(address: string; referer: string; cookies: string; content: string; headers: string): string;
Same as GetPage4, but allows to specify additional headers to provide to the server. They must be encoded using Delphi's TStrings format, i.e. a list of name=value items separated by linebreaks. The default value is an empty string.

function PostPage(address: string; params: string): string;
Pobiera stronę HTML (lub inny plik tekstowy) za pomocą metody POST i zwraca ją jako ciąg znaków.
Parametry muszą być kodowane przy użyciu funkcji URLEncode.

function PostPage2(address: string; params: string; content: string; referer: string; forceHTTP11: Boolean; forceEncodeParams: Boolean): string;
Same as PostPage, but allows to specify also the content-type (instead of the default 'application/x-www-form-urlencoded'), give a "referer" address (default value is an empty string), force the use of HTTP 1.1 (default value is False, for 1.0) and ask to the function to encode the parameters itself (default value is False).

function PostPage3(address: string; params: string; content: string; referer: string; forceHTTP11: Boolean; forceEncodeParams: Boolean; headers: string): string;
Same as PostPage2, but allows to specify additional headers to provide to the server. They must be encoded using Delphi's TStrings format, i.e. a list of name=value items separated by linebreaks. The default value is an empty string.

procedure HTMLDecode(var Value: string);
Dekoduje znaki HTML zawarte w łańcuchu "Value" (np. "&eacute;" -> "é").

procedure HTMLRemoveTags(var Value: string);
Usuwa znaki HTML zawarte w łańcuchu "Value".

function URLEncode(source: string): string;
function URLDecode(source: string): string;
Konwertuje znaki w parametrach URL (np. " " -> "+") i na odwrót.

function GetPicture(address: string): Boolean;
Pobiera obrazek i przypisuje go do bieżącego filmu.

function GetPicture2(address: string; referer: string): Boolean;
Taka sama funkcja jak GetPicture, ale pozwala określić adres "referencyjny" (stronę, która wywołała następną).

function GetPicture3(address: string; referer: string; content: string): Boolean;
Same as GetPicture2, but allows to specify the content-type as a string; by default for other versions the value is '*/*' for compatibility with old versions; you can pass '' for a more standard call.

function GetExtraPicture(extraIndex: Integer; address: string): Boolean;
Pobiera obrazek i przypisuje go do określonego dodatku dla aktualnego filmu.

function GetExtraPicture2(extraIndex: Integer; address: string; referer: string): Boolean;
Taka sama funkcja jak GetExtraPicture, ale pozwala określić adres "referencyjny" (stronę, która wywołała następną).

procedure RaiseConnectionErrors(raise: Boolean);

Ustawia wyrażenie regularne ExprStr.

function RegExprExec(InputStr: string): Boolean;
Znajduje pierwsze dopasowanie na wejściu ciągu InputStr z wyrażeniem regularnym.
Zwraca True, jeśli na wejściu dopasuje regularne wyrażenie, inaczej zwraca False.

function RegExprSetExec(ExprStr, InputStr: string): Boolean;
Taka sama kompinacja z funkcjami RegExprSet i RegExprExec.
Zwraca True, jeśli wyrażenie jest dobrze uformowane i na wejściu ciągu pasuje wyrażenie regularne, w przeciwnym wypadku False.

function RegExprExecNext: Boolean;
Znajduje następne dopasowanie w ciąg znaków z wyrażeniem regularnym.
Zwraca True, jeśli znajdzie dopasowanie, w przeciwnym wypadku False.

function RegExprExecPos(Pos: integer): Boolean;
Znajduje dopasowanie na wejściu ciągu poczynając od określoniej pozycji Pos z regularnym wyrażeniem.
Zwraca True, jeśli dopasowanie zostało znalezione, w przeciwnym wypadku False.

function RegExprSubstitute(TemplateStr: string): string;
Zwraca ciąg TemlateStrg '$&' lub '$0' zastąpiony w całości przez regularne wyrażenie i '$n' zastępuje wystąpienia podwyrażenia #n.

  • Jeśli chcesz umieścić w szblonie '$' lub '\', zastosuj prefiks '\'.
  • Na przykład: '1\$ is $2\\rub\\' -> '1$ is \rub\'.
  • Jeśli chcesz umieścić cyfrę po '$n' musisz oddzielić n klamrami '{}'.
  • Na przykład: 'a$12bc' -> 'abc', 'a${1}2bc' -> 'a2bc'.

function RegExprSetSubstitute(ExprStr, InputStr, TemplateStr: string): string;
Tak samo jak kombinacja z RegExprSet, RegExprExec i funkcją RegExprSubstitute.
Zwraca ciąg TemlateStr z '$&' lub '$0' zastąpione w całości przez wystąpienie r.w. i '$n' zastąpione wystąpieniem podwyrażenia #n.

function RegExprReplace(InputStr, ReplaceStr: string; UseSubstitution: boolean): string;
Zwraca ciąg InputStr z występującym r.w. zastąpionym ciągiem ReplaceStr.
Jeśli UseSubstitution jest True, to ciąg ReplaceStr zostanie użyty jako szablon dla metody Substitution.

  • Na przykład: Wyrażenie := '(block|var)\s*\(\s*(.*)\s*\)\s*';
  • RegExprReplace('BLOCK( test1)', 'def "$1" value "$2"', True); -> 'def "BLOCK" value "test1"'
  • RegExprReplace('BLOCK( test1)', 'def "$1" value "$2"', False); -> 'def "$1" value "$2"'

function RegExprSetReplace(ExprStr, InputStr, ReplaceStr: string; useSubstitution: boolean): string;
Takie same jak połączenie RegExprReplace i funkcji RegExprSet.
Zwraca ciąg InputStr z rwyrażeniem regularnym zastąpionym przez ciąg ReplaceStr.
Jeśli UseSubstitution jest True, to ciąg ReplaceStr zostanie użyty jako szablon dla metody Substitution.

function SubExprMatchCount: Integer;
Zwraca liczbę podwyrażeń stwierdzonych w ostatnim wywołaniu Exec*.
Jeśli nie ma podwyrażenia, ale znaleziono całe wyrażenie (Exec* returned True), then SubExprMatchCount=0.
Jeśli nie znaleziono podwyrażeń ani całych wyrażeń (Exec* returned False) then SubExprMatchCount=-1.
Zauważ, że można nie znaleźć niektórych podwyrażeń i dla takich podwyrażeń RegExprMathPos=RegExprMatchLen=-1 and RegExprMatchStr=''.

  • Na przykład: Wyrażenie := '(1)?2(3)?';
  • Exec ('123'): SubExprMatchCount=2, RegExprMatch(0)='123', (1)='1', (2)='3'
  • Exec ('12'): SubExprMatchCount=1, RegExprMatch(0)='12', (1)='1'
  • Exec ('23'): SubExprMatchCount=2, RegExprMatch(0)='23', (1)='', (2)='3'
  • Exec ('2'): SubExprMatchCount=0, RegExprMatch(0)='2'
  • Exec ('7'): Return False: SubExprMatchCount=-1

function RegExprMatch(SubExprIdx: Integer): string;
Zwraca ciąg podwyrażeń SubExprIdx w ostatnim połączeniu Exec*. (= Copy(InputStr, RegExprMatchPos(SubExprIdx), RegExprMatchLen(SubExprIdx)))
Pierwsze podwyrażenie posiada SubExprIdx=1, ostatnie posiada SubExprIdx=SubExprMatchCount, wszystkie wyrażenia regularne mają SubExprIdx=0.
Zwraca '' jeśli w regularnym wyrażeniu nie ma takiego podwyrażenia lub nie znaleziono go w ciągu wejściowym.

function RegExprMatchPos(SubExprIdx: Integer): Integer;
Zwraca pozycję podwyrażenia SubExprIdx w ostatnim połączeniu Exec*.
Pierwsze podwyrażenie ma SubExprIdx=1, ostatnie ma SubExprIdx=SubExprMatchCount, wszystkie wyrażenia regularne mają SubExprIdx=0.
Zwraca -1 jeśli w regularnym wyrażeniu nie ma takiego podwyrażenia lub nie znaleziono go w ciągu wejściowym.

function RegExprMatchLen(SubExprIdx: Integer): Integer;
Zwraca długość podwyrażenia SubExprIdx w ostatnim połączeniu Exec*.
Pierwsze podwyrażenie ma SubExprIdx=1, ostatnie ma SubExprIdx=SubExprMatchCount, wszystkie wyrażenia regularne mają SubExprIdx=0.
Zwraca -1 jeśli w regularnym wyrażeniu nie ma takiego podwyrażenia lub nie znaleziono go w ciągu wejściowym.

function RegExprModifiers(Modifiers: string): Boolean;
Ustawia wartości domyślne modyfikacji składni wyrażeń regularnych.
Dodając modyfikator 'i','r','s','g','m','x' przed '-' ustawia ją na True i po '-' ustawia ją na False.
Dla przykładu w ciągu 'g-xi' ustawia modyfikator 'g' na True i modyfikatory 'x', 'i' na False.
Uwaga 1: Wszystkie modyfikatory są domyślnie inicjowane jako True.
Uwaga 2: Możesz zastąpić domyślne wartości poprzez dodanie modyfikatorów w wyrażeniu regularnym '(?irsgmx-irsgmx) ...'

  • ModifierI: Rozróżniania wielkość liter.
  • ModifierR: Używa wyrażeń regularnych z rozszerzoną składnią na rosyjski.
    Jeśli True, wówczas ŕ-˙ obejmuje dodatkowo rosyjską literę '¸', Ŕ-ß dodatkowo zawiera '¨', a ŕ-ß zawiera wszystkie rosyjskie symbole.
    Musisz go wyłączyć, jeżeli może to kolidować ze twoim alfabetem.
  • ModifierS: '.' pracuje jak każdy char (również jako [^\n]).
  • ModifierG: Wyłączając modyfikator G przełącza wszystkie operatory w stylu non-greedy.
    Jeśli więc ModifierG = False, to wszystkie '*' pracują jako '*?', wszystkie '+' jako '+?', itd.
  • ModifierM: Traktuje ciąg jak wiele wierszy.
    Oznacza to zmianę `^' i `$' dla dopasowania tylko na początku lub końcu ciągu na początku lub na końcu każdej linii w dowolnym miejscu w ciągu.
  • ModifierX: Użyj składni eXtended, aby umożliwić komentarze w wyrażeniach regularnych
    Pozwala na dodawanie komentarzy w wyrażeniach regularnych, np.: 'wyrażenie regularne # Komentarz'.

Jeśli Debug = True (False jest domyślne), to pojawi się komunikat, gdy wystąpi błąd.

TJvSimpleXml i klasy pochodne

Jest to prawie kompletny parser XML, pozwalający łatwo obsługiwać dokumenty XML. Nie wszystkie funkcje są dostępne przez skrypt, więc poniższa lista zostanie rozszerzona później po dodaniu ich do silnika skryptów.

Tworzenie obiektów jest podobne do TStringList przedstawionej powyżej.

Ma ona następujące metody i właściwości:
procedure LoadFromString(Value: string); - wczytuje dokument XML ze zmiennej
procedure LoadFromFile(FileName: string); - wczytuje dokument XML z pliku
procedure SaveToString: string; - zachowuje bieżący dokument XML w zmiennej tekstowej
procedure SaveToFile(FileName: string); - zachowuje bieżący dokument XML w pliku
property Root: TJvSimpleXmlElemClassic; - koresponduje z elementem "root" dokumentu XML

Różne elementy dokumentu to TJvSimpleXmlElemClassic, oparte na TJvSimpleXmlElem. Ten ostatni ma następujące metody i właściwości:
property Name: string; element name: <name>
property Value: string; element value: <name>value</name>
property Items: TJvSimpleXmlElems; lista składników elementu
property Properties: TJvSimpleXmlProps; lista właściwości (atrybutów) elementu: <name attr1="val1" attr2="val2">
property Parent: TJvSimpleXmlElem element nadrzędny
function GetChildIndex(AChild: TJvSimpleXmlElem): Integer; pozycja w liście (Items) podanego elementu pochodnego
procedure Clear; usuwa wszystkie składniki i właściwości elementu

Klasa TJvSimpleXmlElems ma następujące metody i właściwości:
property Count: Integer zwraca ilość składników w liście
function GetItem(Index: Integer): TJvSimpleXmlElem; daje dostęp do składnika listy przez podanie jego pozycji
function GetItemNamed(Name: string): TJvSimpleXmlElem; daje dostęp do składnika listy przez podanie jego nazwy
procedure Clear; usuwa wszystkie składniki listy
procedure Delete(Index: Integer); usuwa składnik na podanej pozycji
procedure DeleteNamed(Name: string); usuwa składnik o podanej nazwie
function Add(Name: string): TJvSimpleXmlElemClassic; tworzy i dodaje składnik do listy

Atrybuty każdego składnika to TJvSimpleXmlProp, który ma następujące właściwości:
property Name: string; nazwa atrybutu
property Value: string; wartość atrybutu

Są one przechowywane i obsługiwane przez klasę TJvSimpleXmlProps, która ma następujące metody i właściwości:
property Count: Integer; zwraca ilość właściwości w liście
function GetItem(Index: Integer): TJvSimpleXmlProp; daje dostęp do właściwości listy przez podanie jej pozycji
function GetItemNamed(Name: string): TJvSimpleXmlProp; daje dostęp do właściwości listy przez podanie jej nazwy
procedure Clear; usuwa wszystkie właściwości listy
procedure Delete(Index: Integer); usuwa właściwość na podanej pozycji
procedure DeleteNamed(Name: string); usuwa właściwość o podanej nazwie
function Add(Name: string; Value: string): TJvSimpleXmlProp; tworzy i dodaje właściwość do listy

Parametry skryptu

Tytuł, opis i wszystkie pozostałe atrybuty/parametry skryptu mogą być zdefiniowane przy użyciu tego okna. Jest ono dostępne przez ikonę "Właściwości" w edytorze skryptu.

Tytuł skryptu powinien być dość krótki; zazwyczaj jest to nazwa strony z której pobierane są dane. Pole "Pobieranie z internetu" wskazuje czy skrypt może być użyty do pobierania danych z Internetu. Tylko skrypty ze znacznikiem "True" są widoczne w oknie skryptów dostępnych przez "Pobierz informacje" -> "z Internetu używając skryptu". Kiedy okno jest wywoływane przez menu "Skrypty", wszystkie skrypty są widoczne.

Dla każdej opcji, którą zdefiniujesz, możesz określić dostępne wartości (dodatnie liczby całkowite, związane z opisem).

Narzędzia debugowania

Pasek narzędziowy w edytorze skryptów mają komendy podobne do tych dostępnych w Delphi:

  • Przełącznik punktu przerwania: umieszcza punkt przerwania w bieżącej linii, zatem skrypt zatrzyma się po wykonaniu tej linii. Linia będzie podświetlona na czerwono. Możesz umieścić punkt przerwania klikając na lewym marginesie edytora. Tylko punkty przerwania umieszczone na poprawnej linii są używane. Niestety nie jest możliwe oznaczyć wizualnie, które punkty przerwania są niewłaściwe, co robi Delphi podczas wykonywania programu. Gdy wykonywanie skryptu jest zatrzymane, możesz przenieść się do następnej linii przez przycisk "Krok dalej" lub kontynuując wykonywanie przyciskiem "Uruchom".
  • Czyść punkty przerwania: jednym kliknięciem wszystkie punkty przerwania określone w skrypcie.
  • Krok dalej: wykonuje bieżącą linię skryptu (podświetloną na niebiesko) i przechodzi do następnej instrukcji.
  • Uruchom do kursora: wykonuje skrypt do osiągnięcia bieżącej linii (tworzy zatem "wirtualny" punkt przerwania).
  • Analizuj zmienne: wyświeta zawartość zmiennej wskazanej przez kursor.
  • Dodaj śledzenie zmiennej: dodaje do listy śledzenia zmienną wskazaną przez pozycję kursora. Pozwala to określić wartość zmiennej w każdym momencie.
